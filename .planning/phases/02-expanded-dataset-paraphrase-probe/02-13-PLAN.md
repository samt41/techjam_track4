<objective>
Measure the shipped agent once against every generated corpus (D-48), render those records into
their own corpus-baselines table (D-53), compute the two paired contrasts the phase exists to
produce (D-44, MEAS-13), and commit the disclosures the finding depends on being read honestly.

Purpose: this is the phase's measurement. Roadmap Success Criterion 4 asks for a *reported*
generator-affinity gap, and Phase 7 — which depends only on this phase — needs the probe delta with
its sample size and confidence interval. A frozen corpus with no measurement over it would satisfy
none of that. The runs are also a smoke test that every generated corpus actually runs end to end
through the unmodified evaluator.

**The count reconciliation, settled by D-58.** D-45 and D-48 say "five corpora"; D-25's own table
and `02-RESEARCH.md` § 8's corrected budget table both enumerate exactly FOUR — `public`,
`expanded_dev.v1`, `expanded_confirm.v1`, `probe.v1`. **Four is correct.** "Five" is drafting
residue from before D-46 consolidated the probe's three arms (`control`, `probe_sonnet`,
`probe_haiku`) into a single `data/probe.v1.jsonl`, and D-58 corrects D-45 and D-48 to four.

D-58 also settles what to do about `public`: **re-run it, at the current code revision, like the
other three.** FOUR new runs, FOUR rows. Do not carry the existing `experiments/baselines/run-a`
record into this table. `run-a` was recorded at code revision `5a978e7f`, and commit `f6c91e8` has
since changed `arena/`; a table mixing one row from an old revision with three from the current one
cannot honestly assert the shared configuration that makes its rows comparable, which is exactly
the assertion task 3 makes. Re-running `public` costs ~6 minutes of compute and buys the one
property that makes a baselines table worth reading.

`run-a` remains committed as prior-revision history and is untouched by this plan. It is NOT a row
in `corpus_baselines.json`.

`expanded_confirm.v1` IS included here. D-27 seals it against Phases 3-4 iteration; D-48's single
baseline measurement is the one permitted read before Phase 5, and it is what makes the
confirmation draw usable when Phase 5 arrives.
</objective>
