<objective>
Build the build-time LLM authoring driver: a committed prompt pack, a `subprocess`-based `claude -p`
runner behind an injected `Protocol`, a frozen digest-plus-parsed-result replay log (D-50), and the
provenance record D-43 consumes — with the D-35 context-isolation and D-57 anti-contamination
properties asserted by argv introspection rather than hoped for.

Purpose: this phase has no in-repo precedent for driving an external interactive tool. The only two
`subprocess` call sites in shipped code run `git` with a fixed argv, no stdin, no timeout and no
output parsing. Everything here is new, and three of its properties are security- and
methodology-load-bearing: `claude -p` auto-discovers this project's `CLAUDE.md`, which both costs
~31k prefix tokens per cold call AND tells the authoring model exactly what the probe is for — an
anti-circularity breach, not merely a cost bug (D-57, L-12). `--bare` would be stronger isolation
but its own help text excludes OAuth, so it cannot be used.

Output: `arena/datasets/authoring.py`, three committed revision-hashed prompt files, and a test
module that never shells out.
</objective>
