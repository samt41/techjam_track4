<objective>
Define the corpus row schema as frozen validated dataclasses, the canonical JSONL serializer, and
the two-layer D-37 authored-branch conformance check — plus the catalog-free fixture module every
other test in this phase builds on.

Purpose: Roadmap Success Criterion 1 requires that every generated session takes the evaluator's
authored `intent_card` + `behavior` branch, "verified programmatically, not assumed". The branch-1
predicate at `evaluator/local_evaluator.py:205` is membership only — a row with
`"intent_card": null` takes branch 1 and then crashes downstream — so the static validator is
load-bearing, not belt-and-braces. Because branch 1 returns before touching `products`, the dynamic
identity check runs with `products={}` and needs neither the 61 MB catalog nor the 580 MB artifact,
which is what keeps the suite catalog-free.

Output: `arena/datasets/schema.py`, `tests/dataset_fixtures.py`, and the two MEAS-10 test modules.
</objective>
