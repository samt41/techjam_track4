Wire the three new operator entry points into `arena/run_arena.py`: registry-name resolution for
`--dataset`, a `contrast` subcommand for the D-44 paired readout, and a `corpus-baselines`
subcommand for the D-53 table — plus the `main(argv)` signature change that makes all of it testable

`--dataset` today is a bare filesystem path with no registry concept, so nothing checks that the file
being measured is the file whose digest was frozen (Pitfall 6). Second, L-11: `run_arena.py:56-96`
documents that unset override flags are OMITTED from the fingerprint, so D-48's "using the existing
`run-a` spec" is only literally reproduced when the invocation types
`--exploration disabled --lexical-mode auto`; a flag-free invocation records `{}` and mints a
different fingerprint while configuring a byte-identical Agent.

Output: three CLI surfaces, a testable `main(argv)`, and their tests.
